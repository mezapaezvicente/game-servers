# example-game

This is a filled-in copy of `_template/`, kept as a working reference for
what a real game directory looks like. It uses a placeholder image and
health check because the exact game/mods for this box aren't decided yet.

When you set up the first real game, either fill this directory in for
real (replace the placeholder image and health check, keep the name or
rename the directory) or copy `_template/` fresh and delete this one.
Don't leave it as dead placeholder config once a real game exists — it
should always be either a working reference or gone.

See `../../_template/README.md` for what each file does and
`../../PORTS.md` for the port this reserves.
